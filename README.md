# HITMAN Perks

Perks for HITMAN World of Assassination: pick upsides and drawbacks that change how a mission plays.

Perks comes in two halves, and both are needed:

- **Perks.dll** - an SDK mod (ZHMModSDK). Install it in `Retail\mods` and enable it in the SDK.
- **Perks SMF content** - a Simple Mod Framework mod (`buddhasferret.Perks`), deployed with SMF.

Downloads and installation instructions are on the Nexus Mods page. This repository hosts the SMF content's releases, so SMF can show Perks updates and install them with one click. SMF doesn't update SDK mods: Perks.dll updates come from Nexus.
